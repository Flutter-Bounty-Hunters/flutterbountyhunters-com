Sync strategies

The plan covers drafts and merging, but it doesn’t choose a sync strategy yet. Two would fit.

Offline sync
Compare last write wins with an edit queue for this app.

Your crews are offline for hours, so queue the edits. A queue keeps what everyone meant when their changes meet again.

Last write winsEdit queue
Offline editsNewest replaces the restAll kept, in order
EffortAbout a dayOne to two weeks
Best forSettings and profilesShared documents

Start here

  1. Store each edit in SyncQueue before it’s sent.
  2. Replay the queue when the signal comes back, oldest edit first
Turn this into tasks for the mobile team. Each one needs:
  • an owner
  • a way to test it offline
